# 都市重生文风

这种文风读起来像一个很会讲故事的朋友在你旁边说话：嘴碎、好笑，但写到人心软的地方会突然安静下来。核心有三点：

1. **叙述者有态度**：贴着主角写，主角的吐槽直接混进叙述。
2. **景里有烟火气**：环境描写写的是早餐摊、路灯、菜市场、流浪猫，不是空泛的"美景"。
3. **情绪靠动作**：越动情的地方句子越短，用一个小动作代替一段抒情。

---

## 一、叙述声音

1. **贴身第三人称**：用第三人称，但主角的内心吐槽可以直接写进叙述，不加引号。
   - 写法："他心想……" / "他心说……" 后面直接跟口语化的吐槽。
2. **单句旁白**：在一段情节结束后，可以单独起一段写一句短议论，像旁白点评。要求平实、不说教，一章最多出现 2~3 次。
   - 原著例："人在江湖，身不由己。"
3. **切换到配角视角**：偶尔写配角怎么看主角。配角的误解越大，下一段揭示真相时反差越强。
   - 结构：配角的判断 → "XX是这样觉得的。" → 另起一段 "实际上，……"
4. **用昵称代替名字**：给重要人物起带态度的外号或称呼（如"X太后""X姐""狗男人"），在叙述里替换使用。昵称本身就是叙述者的表情。

## 二、幽默

1. **雅俗、古今混搭的比喻**：把校园、职场里的小事比作宫廷、武侠、动画片里的场面。
2. **偷换概念的对答**：主角被质问时，不正面回答，而是抓住对方话里的一个词转向。
   - 原著例："只有丑的才谈恋爱，我们美的卖空调"
   - 示范：
     > "你这人到底有什么优点？"
     > "诚实。"
     > "那缺点呢？"
     > "太诚实。"
3. **章末反转**：一章或一个场景的最后一句，用一句冷幽默、一个反转或一个小悬念收住，后面接"······"。

## 三、环境描写（核心）

### 规则
1. **放在转折处**：环境描写插在对话结束后或情绪变化时，起"换气"作用。不要在章节开头连写三段风景。
2. **一段一句**：一段 60~150 字，用逗号连成一个长句，中间尽量不用句号。
3. **按这个顺序写**：
   **时间/季节锚点 → 大景（天空、光线）→ 中景（街上的人在做什么）→ 一个会动的小细节 → 落回一句朴素的感受**
4. **选烟火气意象**：早餐摊的蒸汽、路灯下的飞虫、网吧通宵出来的学生、晒在马路上的麦粒、广场喷泉边的小孩、巷口的流浪猫、菜市场里甩尾巴的活鱼。
5. **雅俗对冲**：写到古迹、名校、豪宅等"雅"的东西时，紧接一笔市井细节拉回地面。
6. **比喻用日常物**：用吃的、玩具、家常物件比喻天空和自然，并把比喻再延展一步。引导词优先用"好像""就好像"，少用"宛若""恍若"。
7. **拟人带一点调皮**：动物和景物可以有小情绪，但只点一笔。
8. **以景反衬**：最有力的写法是"景很热闹，人很难过"或"外面很冷，屋里很暖"。
9. **加气味和温度**：每段环境描写至少带一种气味或体感温度。

### 示范（新写，非原文）
- 完整的一段：
  > 十二月的建邺已经冷透了，天色灰扑扑的压在梧桐枝头，路边烤红薯的铁桶冒着白气，几个刚下晚自习的学生缩着脖子围过去，路灯一亮，呵出来的雾气都被照成了暖黄色，闻着那股焦甜味，他忽然有点想家。
- 日常物比喻并延展：
  > 傍晚的云被夕阳烤得边缘焦黄，好像刚出锅的千层饼，一层叠着一层，再晚一点，连香味都要飘下来了。
- 调皮的拟人：
  > 巷口那只橘猫蹲在电瓶车坐垫上，抬眼看了看他，大概觉得不值得起身，又把脑袋埋回了尾巴里。
- 以景反衬：
  > 操场上全是迎新晚会的彩排声，鼓点一下比一下热闹，不过这些热闹好像都隔着一层玻璃，一点也落不到她身上。
- 雅俗对冲：
  > 老校区的法国梧桐有一股旧时代的浪漫，鸡鸣寺的钟声隔着半条街悠悠传过来，可惜校门口煎饼摊的葱花味更霸道，一下就把人拽回了现实。

## 四、细腻感

1. **用小动作代替情绪词**：不写"她很委屈""他很紧张"，写一个这种情绪下才会做的小动作。
   - 示范：
     > 她没接话，低头把奶茶吸管拆了出来，又慢慢插回去。
     > 他伸手之前，先把手心在裤子上蹭了蹭。
2. **翻译潜台词**：人物做了一件别扭的事之后，叙述者用口语把背后的意思点破。
   - 结构："其实这里面的意思很明显——……"
   - 示范：
     > 电话被挂了三次，但一直没关机。这意思很明显——我没想不理你，但你得先把我哄好。
3. **精确的小数字**：用具体的秒数、次数、金额制造心理真实感。
   - 原著例："才42秒。"
4. **高潮写短**：情绪最浓的地方，用一句最短的对话收住，不加任何抒情。
   - 原著例："不辣，甜的。"
5. **两难用对称句**：人物陷入两难时，用一个对称句收束。
   - 原著例："抬头是地狱，低头亦是地狱"
6. **长辈的爱写笨拙**：父母的关心通过失眠、唠叨、动手、嘴硬表现，不写他们说出"我爱你"。

## 五、人物出场

1. **给每个主要角色一个固定标志物**（某种眼型、发型、一个小习惯），之后反复使用，让读者一看就知道是谁。
2. **顺序**：整体印象 → 衣着（颜色 + 材质 + 款式要具体）→ 一个五官重点 → 一个动作 → 旁人的反应。
3. **用衣着暗示身份**：洗到掉色的旧校服、穿到发灰的白布鞋说明家境；衬衫上一个很小的奢侈品标志说明低调富贵。
4. **克制**：外貌描写一次不超过 80 字，只写有作用的细节，不堆形容词。
   - 示范：
     > 她今天把头发扎成了低马尾，一件洗得发软的灰色卫衣，袖口卷了两道，素着一张脸站在门口，反倒比旁边化了妆的女生更扎眼，路过的两个男生都放慢了脚步。

## 六、对话与排版

1. 段落要短，大量单句成段；每句对话单独成段。
2. 对话标签放在后面，用"说道/问道/回道"，或者用一个动作代替标签。
3. 拟声词、语气词可以单独成段，例如 "呼。" "嘭嘭嘭······"
4. 对话口语化，可以带方言和语气词（嘛、噢、哈、昂）；熟人之间的对话可以损、可以带粗口。
5. 用"······"做场景切换和留白。
6. 并列心理用分号：
   > 高兴的是，……；
   > 难过的是，……。
7. 写一群人的反应时，用"众生相"写法：一个人一句，用分号隔开。
8. 如果故事有年代背景，加入那个年代的具体物件和流行歌曲，可以把歌词直接插入正文做背景音。

## 七、禁止清单

1. 不写大段抽象的心理独白来抒情。
2. 情绪高潮处不堆形容词，不写"泪水夺眶而出""心如刀割"这类现成说法。
3. 不写纯粹的风景；风景必须服务于人物当下的心情或节奏。
4. 不用生僻字和成串的四字成语；出现雅词时，马上用一个俗事对冲。
5. 不让主角直接说出主题；主题由旁人议论或单句旁白点到即止。
6. 单句旁白不要说教，不要用"人生就是……"这类鸡汤句式开头。
7. 不连续两段都用"仿佛""宛如"打比方。

## 八、写作流程

1. 先确定这个场景的**情绪基调**，以及它是放松的、紧张的还是转折的。
2. 写对话和动作，推进情节。
3. 在情绪转折的地方插一段环境描写，按第三节的顺序写。
4. 在动情处检查：有没有用一个小动作代替情绪词？最后一句够不够短？
5. 在结尾检查：有没有一句反转、冷幽默或余韵收住？

## 九、自检清单

写完一段后逐条检查：

- [ ] 叙述里有没有主角的态度或吐槽，而不是中性的"摄像机视角"？
- [ ] 环境描写是否放在转折处，是否有时间锚点、一个会动的小细节和一种气味或温度？
- [ ] 比喻是否用了日常物，是否延展了一步？
- [ ] 动情的地方是否用了小动作，没有直接写情绪词？
- [ ] 情绪最浓的地方，是否是全段最短的句子？
- [ ] 段落是否够短，对话是否单独成段？
- [ ] 结尾是否有反转、冷幽默或留白？
- [ ] 是否触犯了禁止清单中的任何一条？
