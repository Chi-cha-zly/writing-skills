# writing-skills

中文小说写作 skill，以及一个用来从 epub 小说中抽样素材、提炼文风的小工具。

## 内容

```
writing-skills/
├── skills/
│   └── urban-rebirth-style/   # 都市重生文风写作 skill
│       └── SKILL.md
└── tools/
    └── slice.py               # epub 抽样切片工具
```

## Skill：urban-rebirth-style

用"都市重生网文"的风格写中文小说段落，参考了这类网文常见的叙述方式和描写手法。

- **叙述声音**：贴着主角写的第三人称，主角的吐槽直接混进叙述，配有单句旁白和配角视角。
- **环境描写**：按"时间锚点 → 大景 → 中景 → 动态小细节 → 落回感受"的顺序写，意象偏市井烟火气，比喻用日常物件。
- **细腻感**：用小动作代替情绪词，替读者翻译潜台词，情绪高潮处反而写得最短。
- **人物、对话与排版**：给角色固定标志物，段落短、对话口语化。
- **配套工具**：禁止清单、写作流程和自检清单。

适合写都市、校园、重生、日常情感类章节，也可以用来把一段平淡的稿子改写成这种风格。

### 安装

**Claude Code**

把 skill 文件夹复制到 `~/.claude/skills/`（所有项目可用），或者项目的 `.claude/skills/` 下（仅当前项目可用）：

```bash
git clone https://github.com/Chi-cha-zly/writing-skills.git
cp -r writing-skills/skills/urban-rebirth-style ~/.claude/skills/
```

之后在对话里提到"用都市重生文风写……"，Claude 会自动加载这个 skill。

**Claude 网页版 / App**

把 `skills/urban-rebirth-style` 文件夹打包成 zip，在设置中上传。

**其他模型（GPT 等）**

把 `SKILL.md` 的正文（frontmatter 之后的部分）复制进系统提示词或自定义指令即可。

### 使用示例

```
用都市重生文风写一段 500 字左右的场景：雨后黄昏，女主角独自回到童年住过的老房子。
写完后对照 skill 的自检清单逐条检查。
```

## 工具：slice.py

从 epub 小说中抽样，生成用于文风分析的素材，方便你为自己喜欢的小说提炼新的文风 skill。

它会做三件事：

1. 按 epub 的阅读顺序识别章节，自动跳过封面、目录和版权页。
2. 在全书开头、中段、结尾**均匀抽取**若干完整章节。
3. 按"感官词多、对话少"的规则打分，挑出描写密度最高的段落。

结果按字数分批输出到 `slices/<书名>/batch_XX.txt`，每批可以直接交给模型做文风分析。

### 使用

只依赖 Python 3 标准库，不需要安装其他包：

```bash
python3 tools/slice.py "小说文件名.epub"
```

可以在脚本开头调整参数：

| 参数 | 默认值 | 含义 |
|---|---|---|
| `N_CHAPTERS` | 12 | 完整保留的章节数 |
| `N_PARAS` | 150 | 额外挑出的高描写密度段落数 |
| `BATCH_CHARS` | 25000 | 每批字数 |
| `MIN_CHAPTER` | 500 | 少于这个字数的文件会被当作封面或版权页跳过 |
| `SENSE` | 一串感官字 | 打分用的关键字，可以按小说题材增删 |

### 提炼文风的流程

1. 用 `slice.py` 生成素材，人工删掉不需要的片段（作者求票留言、打赏名单等）。
2. 把每批素材交给模型，从用词、句式节奏、环境描写、细腻感、对话、"作者不做的事"几个维度分析，每条结论附简短原文证据。
3. 汇总所有批次的分析，写成 `SKILL.md`。规则要写成可执行的指令，示范句要新写，不要照搬原文。
4. 用 skill 实际写一段，和原著对比，再迭代规则。
